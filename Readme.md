# Production Planning System

Система планирования производства с диаграммой Ганта.

## Функциональность
- Управление оборудованием и типами оборудования
- Управление заказами с системой приоритетов
- Планирование работ на оборудовании
- Визуализация в виде диаграммы Ганта
- Экспорт в Excel
- Горячие клавиши для навигации

## Установка
```bash
pip install -r requirements.txt
streamlit run main_streamlit.py
